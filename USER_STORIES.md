# Aetherlab — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of AI platform

- As a platform head, I want one inventory of every model and endpoint, so that shadow AI cannot hide in personal accounts.
- As a platform head, I want GPU spend by model, so that I can stop zombie training jobs.

### Data scientist

- As a data scientist, I want a guided path from framing to deploy that is faster than asking IT for VMs, so that I prefer the factory.
- As a data scientist, I want to register transfer-learning bases easily, so that I am not punished for using model zoos.

### Model risk validator

- As a validator, I want business-goal evaluation artefacts before I sign, so that I am not rubber-stamping AUC.
- As a validator, I want lineage and approval history in one pack, so that exams do not become archaeology.

### Use-case product owner

- As a product owner, I want monitor alerts tied to my business KPI, so that I know when to retrain.
- As a product owner, I want clear retirement of superseded models, so that customers are not on stale logic.

### Cloud security admin

- As a security admin, I want purpose-bound dataset access grants, so that training access expires.
- As a security admin, I want blocked deploys when monitors are missing, so that controls are not optional.

### Internal audit

- As an auditor, I want reproducible evidence packs, so that sampling production AI is tractable.
